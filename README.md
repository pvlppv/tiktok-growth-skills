# tiktok-growth-skills

Claude Code skills for growing an app on TikTok with photo slideshows.

| Skill | Does |
|---|---|
| [Pinterest Photo Finder](skills/pinterest-photo-finder/SKILL.md) | Finds full-size photos, drops blurry and duplicate ones |
| [TikTok Viral Researcher](skills/tiktok-viral-researcher/SKILL.md) | Finds viral carousels and shows how competitors post |
| [TikTok Slideshow Generator](skills/tiktok-slideshow-generator/SKILL.md) | Turns text and photos into slides, text never on faces |
| [TikTok Auto Poster](skills/tiktok-auto-poster/SKILL.md) | Posts to all your accounts daily, after your OK |
| [App Growth Analyzer](skills/app-growth-analyzer/SKILL.md) | Shows which posts brought App Store downloads |

## Install

```bash
git clone https://github.com/pvlppv/tiktok-growth-skills
cp -r tiktok-growth-skills/skills/* ~/.claude/skills/
```

Then ask Claude, e.g. "find me cozy desk photos".

Best on a Mac (uses Apple Vision).
